## AIエージェントとは？

**ChatGPT** = 質問に答える（会話のみ）

**AIエージェント** = 質問を理解して**実際に作業する**

```
「ファイルを作って」→ 本当にファイルが作られる
「コードを修正して」→ 本当にコードが変わる
```

**考える + 行動する = AIエージェント**

```
┌─────────────────────────────────────────────┐

│                                             │

```

## ReActパターン

**ReAct = Reasoning + Acting**

| ステップ | 説明 | 例 |
|---------|------|-----|
| 1. 考える | 何をすべきか判断 | 「ファイル一覧が必要だ」 |
| 2. 行動する | ツールを実行 | list_dir を呼び出す |
| 3. 観察する | 結果を確認 | 「sample.txt がある」 |

↓ **必要なら繰り返す**

kakko-de はこのパターンをシンプルに実装

---

## 3つの構成要素

### 1. LLM（大規模言語モデル）
- 考える役割（何をすべきか判断）

### 2. ツール
- 行動する役割（ファイル操作、API呼び出し等）

### 3. ループ
- LLM → ツール → LLM → ... を繰り返す

**たったこれだけ！**

---

## LLMの本質

### 巨大なオートコンプリートマシン

LLM は「次に来る可能性が高い単語を予測する」装置

```
入力: 「今日の天気は」
予測: 「晴れ」「曇り」「雨」...（確率順）
```

**Gmail の予測変換を超巨大にしたもの**

---

## なぜツールが使えるのか？

### 正直、完全には解明されていない

しかし、オートコンプリートの延長として理解できる：

```
入力: 「ファイル一覧を教えて」
予測: 「list_dir ツールを使うべき」← 学習データのパターンから
```

**大量のコード・ドキュメントを学習した結果**
→ 「こういう時はこのツールを使う」パターンを習得
