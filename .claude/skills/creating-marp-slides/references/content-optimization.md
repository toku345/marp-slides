# コンテンツ最適化

スライドのオーバーフロー（画面に収まらない）を防ぐガイドライン。

## コードブロックの長さ

長いコードブロックはスライド下部が見切れる原因。

**悪い例**: 長い echo コマンドで YAML 全体を出力
**良い例**: 簡潔なコマンドのみ表示

## 1スライドの情報量

- 箇条書きは 5-7 項目まで
- 複雑な内容は複数スライドに分割

## 数式の配置

- ブロック数式（`$$...$$`）は縦スペースを大きく消費
- 可能ならインライン数式（`$...$`）を優先

## 検証方法

```bash
bun run preview
```

slide-reviewer エージェントで Playwright を使った自動検証も可能。
